# Psychology Dashboard — Color Palette

## Colors Used

| Element           | Color     | Name         |
|-------------------|-----------|--------------|
| Sidebar           | `#3D2540` | Deep Plum    |
| Active nav bar    | `#EAA7C7` | Pink Quartz  |
| Content bg        | `#F7EEF5` | Soft Pink    |
| Primary buttons   | `#B5526E` | Rose         |
| Card backgrounds  | `#FBF5F9` | Blush        |
| Card borders      | `#E8D8E4` | Dusty Pink   |
| Success / Tea     | `#245E55` | Tea Green    |
| Danger            | `#C63F3E` | Red Passion  |
| Text              | `#2D2D2B` | Muted Black  |

## Reasoning

- **Deep Plum sidebar** — sets a calm, introspective tone fitting psychology as a discipline.
- **Pink Quartz active bar** — soft and warm; stands out against the dark sidebar without being jarring.
- **Blush/Soft Pink cards** — never plain white; the tint keeps the palette cohesive and easy on the eyes.
- **Rose primary action** — mid-tone rose bridges the dark plum and light blush, clearly marking interactive elements.
- **Tea Green / Red Passion** — shared across all roles for success/danger states to maintain system-wide consistency.
